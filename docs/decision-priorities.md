# Executive decision priorities

The decision sponsor supplied the following ordered priorities on 2026-10-07:

1. Reliability and correctness
2. Security
3. Performance
4. Cost
5. Governance, expandability and scalability

These are ordinal priorities, not invented numerical weights. Board-facing
recommendations must first exclude frameworks with failed or unvalidated
mandatory reliability/security evidence. They may then compare performance and
cost only within equal deployment modes and disclosed operating assumptions.

Before a final weighted recommendation, the sponsor must approve cardinal
weights for the selected use case. Until then, this order is used as the
tie-break rule and is recorded in every decision pack.
